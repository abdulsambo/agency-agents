Play over the same Wi-Fi

  1. On a computer, put index.html and server.js in one folder (both are in apps/chess-duel).
  2. Install Node.js if you don't have it, then run node server.js in that folder.
  3. It prints an address like http://192.168.1.20:8080. Open it on both devices.
  4. One of you presses Create game, and the other types the code.

Play through Claude

  1. Share this page with your friend from its page on claude.ai. They need a Claude account with access to it.
  2. Both of you open it, then create and join with a code as above.
  3. This works from anywhere, not just the same Wi-Fi.

Play on one device

  1. Press Play on this device and pass the phone or laptop back and forth.
  2. Turn on "Flip the board each turn" so each player sees the board from their own side.
